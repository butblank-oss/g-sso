## 4. 버튼 상태 9가지
기본 Default · 호버 Hover · 눌림 Pressed · 포커스 Focus(키보드 Tab) · 비활성 Disabled(조건 미충족) · 로딩 Loading("저장 중") · 성공 Success · 오류 Error · 선택됨 Selected(예: 팔로잉).
> AI에게: "버튼을 기본, 호버, 눌림, 비활성, 로딩, 성공, 오류 상태별로 다 만들어 줘"

## 5. 화면 이동 9가지 (내비게이션)
하단 탭바 Tab bar(화면 위에 떠 있는 캡슐형은 플로팅 탭바 Floating tab bar) · 상단 탭 Top tabs · 드로어 Navigation drawer · 브레드크럼 Breadcrumb · 고정 헤더 Sticky header · 플로팅 버튼 FAB · 페이지네이션 Pagination · 무한 스크롤 Infinite scroll · 뒤로 가기 Back navigation
> 탭바 동작: 슬라이딩 인디케이터 Sliding indicator · 컨텍스트 탭바 Contextual tab bar(+ 떠 있는 뒤로 가기) · 탭바 말풍선 Tab bar tooltip · 새 소식 점 Badge dot.
> 앱 바 종류: 큰 제목 Large title(스크롤하면 작은 제목으로 접힘 = 접히는 큰 제목 Collapsing large title) · 뒤로 가기형 · 닫기형(몰입 플로우).

## 11. 빈 화면 9가지
| 이름 | 상황 | 다음 행동 예 |
|---|---|---|
| 첫 사용 First use | 처음 들어와 아무것도 없음 | "구경하러 가기" |
| 검색 결과 없음 | 검색어 결과 0 | 검색어 바꿔 보기 제안 |
| 필터 결과 없음 | 필터 결과 0 | 필터 해제 |
| 오프라인 Offline | 연결 끊김 | 다시 시도 |
| 권한 필요 | 알림/위치 권한 없음 | 권한 켜기 토글 |
| 모두 완료 All caught up | 할 일 다 끝냄 | 다음 미션 안내 |
| 삭제 직후 Emptied | 장바구니 비움 | 되돌리기/쇼핑 계속 |
| 오류 화면 Error state | 불러오기 실패 | 다시 시도 |
| 잠김 Locked content | 회원 전용 | 로그인/열어 보기 |
> 규칙: 빈 화면마다 **다음에 누를 것 하나**를 반드시 준다.

## 24. 숨은 UX: 당겨서 새로고침
- 트위터 앱 개발자 로렌 브릭터가 처음 만든 동작. 원래는 새로고침 버튼 대신 손으로 당기게 한 작은 아이디어.
- 매번 결과가 달라지는 **가변 보상** 구조라 슬롯머신처럼 계속 당기게 된다. 만든 사람도 나중에 "중독적"이라고 말함(2017).
- 그래서 인스타그램은 피드 끝에 **"다 봤어요"** 표시로 멈출 곳을 만들었다.
> 지쏘 원칙: 무한 피드에는 멈출 곳(모두 완료 표시)을 둔다.
