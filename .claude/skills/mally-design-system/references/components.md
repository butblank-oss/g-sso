# 맬리 컴포넌트 규칙

클래스는 `components.css`, 값은 `tokens.css` 변수.

## AdminShell

치매안심센터 담당자용 관리자 웹(PC) 기본 틀. 왼쪽 사이드바 + 오른쪽 본문.

- 사이드바 `admin-sidebar-width`, 진한 면 `green-950` 위 흰 로고, 선택 메뉴 흰 글자 굵게.
- 본문 안쪽 `space-8`, 제목 `admin-title`, 기준일 `admin-caption`. KPI는 `m-kpis` 3열.
- 최소 폭 1280px. 정보 밀도를 높여도 된다(본문 15px, 최소 13px). 호버 상태를 반드시 만든다.

## AppBar

화면 맨 위 바. **화면 종류별로 세 가지 중 하나만** 쓴다.

| 종류 | 언제 | 모양 |
|---|---|---|
| 큰 제목형 | 탭 첫 화면 | `fs-title-lg` 큰 제목 + 오른쪽 아이콘. 스크롤 36px를 넘으면 유리 면 작은 제목 바(`fs-headline`)가 나타난다(접히는 큰 제목) |
| 뒤로 가기형 | 탭 안 하위 화면 | 작은 제목 바 고정. 탭바는 보인다 |
| 닫기형 | 몰입 플로우 | 진행 막대 + "1 / 5" 왼쪽, 닫기(X) 오른쪽 위. 누르면 "그만할까요?" 확인. 탭바는 숨긴다 |

| | iOS | 안드로이드 |
|---|---|---|
| 작은 제목 | 가운데 | 왼쪽 |
| 뒤로 가기 | ‹ + 이전 화면 이름 | ← 아이콘 |

- 높이 `appbar-height`, 누르는 요소 `touch-min`. 접힘은 `opacity`·`transform`만.

## Badge

성취를 축하하는 배지. 하루 미션을 모두 마쳤을 때처럼 큰 일에만 쓴다.

- 원형 메달(`primary` 위 `on-primary` 숫자) + 제목 + 설명 한 줄. 등장은 `ease-spring-soft`.
- 새 소식 점(`m-dot`, `badge-dot`)은 아이콘·탭 오른쪽 위 8px. 숫자 배지는 쓰지 않는다.

## BottomSheet

아래에서 올라오는 선택·상세 창(미션 상세, 약관 보기, 순위). 꼭 멈춰야 하는 결정은 Dialog.

- 위 모서리 `radius-sheet`, 손잡이 40×5, `shadow-sheet`, 뒤 딤 `scrim`. 안쪽 `space-5`.
- 층: 딤 50·시트 51로 **탭바보다 위**.
- 모션: 열림 `duration-enter`+`ease-enter`, 닫힘 `duration-exit`+`ease-exit`. 오버슈트 금지.
- 포커스: 다 올라온 뒤 `focus({preventScroll:true})`. 닫힌 동안 `visibility:hidden`, 닫으면 연 버튼으로 포커스 복귀.

## Button

행동을 실행하는 버튼. 한 화면에 주요(primary) 버튼은 하나만 둔다.

| 종류 | 클래스 | 쓰는 곳 |
|---|---|---|
| 주요 | `m-btn--primary` | 화면의 단 하나의 다음 행동 |
| 보조 | `m-btn--secondary` | 주요 버튼 옆 대안 |
| 텍스트 | `m-btn--ghost` | "나중에 할게요" 같은 가벼운 선택 |

- 크기: 기본 `button-height`(56), 작게 `m-btn--sm`(48). 모서리 `radius-md`, 글자 `fs-headline` 굵게.
- 상태 9종을 모두 만든다: 기본 · 호버 · 눌림 · 포커스 · 비활성 · 로딩("~하는 중") · 성공 · 오류 · 선택됨.
- 문구는 결과를 말하는 동사: "가입 완료하기". "확인"만 쓰지 않는다.

## Checkbox

여러 개를 고르고 저장해야 반영되는 선택. 바로 반영되는 켜고 끄기는 Switch.

- 한 줄 전체가 눌리는 영역(`m-check`, 높이 `touch-min`).
- 약관: 전체 동의와 개별 동의를 연동한다. 하나라도 풀면 전체 동의도 풀린다.
- 필수/선택은 태그로 표시. **선택 항목을 미리 체크하지 않는다**(다크패턴).
- 꺼짐 테두리 `border-control`(3:1), 켜짐 `primary` 채움.

## Chip

카테고리나 상태를 짧게 표시하는 알약. 누르는 필터가 아니면 버튼처럼 보이지 않게 둔다.

- `m-chip`(카테고리), `m-chip--neutral`(중립 상태), `m-chip--warning`(예정·주의), `m-streak`(연속 기록).
- 글자 `fs-label-sm` 굵게, 색 `text-accent`. 연속 기록은 사실만(가짜 마감·가짜 희소성 금지).

## DataTable

관리자 웹 목록 표(참여자·훈련 기록).

- 머리 행 `surface-sub` + `fs-label-sm`, 본문 `fs-label`. 숫자는 오른쪽 정렬 + 고른 폭(`m-num`).
- 상태는 색만 쓰지 않고 칩 글자로("완료", "미참여"). 행 호버 `surface-sub`.
- 결과가 없으면 EmptyState("조건에 맞는 참여자가 없어요 · 필터 초기화").

## Dialog

멈추고 결정해야 할 때만 쓰는 확인 창. **iOS와 안드로이드 모양이 다르다.**

| | iOS 알림창 `m-alert` | 안드로이드 다이얼로그 `m-dialog` |
|---|---|---|
| 정렬 | 가운데 | 왼쪽 |
| 버튼 | 아래 가로 2칸: 취소 왼쪽, 확인 오른쪽 굵게 | 오른쪽 아래 텍스트 버튼: 취소 → 확인 |

- 제목은 질문, 버튼은 동사: "훈련을 그만할까요?" / "계속하기", "그만하기". 위험한 행동은 `error` 글자.
- 거절 버튼에 죄책감 주는 문구 금지. 가벼운 알림은 Toast.

## EmptyState

보여줄 것이 없는 화면. **다음에 누를 행동 하나를 반드시 둔다.**

- 맬랑이(120px) + 제목(`fs-headline`) + 설명 한 줄 + 버튼 하나. 안쪽 `space-6`.
- 상황별 맬랑이: 모두 완료=활짝 웃기, 첫 사용=손 흔들기, 검색 결과 없음·오류=생각 중, 권한 필요=일정 확인.

## GameCard

두뇌 게임 목록 항목. 게임 썸네일(피그마 '두뇌게임 썸네일 리스트') + 이름 + 소요 시간.

- 썸네일 64px, 모서리 `radius-md`. 썸네일의 색 타일 배경은 그림의 일부라 그대로 둔다(UI 색으로 쓰지 않는다).
- 이름 `fs-body-lg` 굵게, 메타 `fs-caption`. 행 전체가 눌리고 오른쪽에 › 표시.
- 썸네일 17종: 기억의 숨바꼭질, 오늘의 장바구니, 숨은 헬씨 찾기, 꿀벌의 숫자놀이, 초성퀴즈, 재밌는숫자퍼즐4x4, 구슬옮기기, 기찻길만들기, 숨은 헬씨찾기 비밀작전, 양말 정리 대작전, 진짜 색깔 찾기, 단어기억하기, 알쏭달쏭숫자더하기, 재밌는숫자퍼즐9x9, 색깔맞추기, 바이러스 퇴치, 타일뒤집기.
- 확인 필요: '타일뒤집기'와 '기억의 숨바꼭질'은 피그마에서 같은 그림이다.

## Healthy

헬씨들: 맬랑이와 함께 나오는 친구 캐릭터 117종(피그마 '맬리 그래픽 에셋 모음 › 헬씨들'). 일러스트로만 쓴다.

| 줄 | 묶음 | 수 |
|---|---|---|
| 1 | 노랑·주황·빨강 친구 | 28 |
| 2 | 파랑·보라 친구 | 27 |
| 3 | 분홍 친구 | 11 |
| 4 | 장면·그룹·말풍선 | 26 |
| 5 | 맬랑이(초록) | 23 |
| 6 | 기타 | 2 |

- **캐릭터 색은 그림 안에서만**: 노랑·파랑·분홍 등을 버튼·칩·배경 같은 UI 색으로 가져오지 않는다.
- 한 화면에 캐릭터 그림은 하나(장면 그림 포함). 글자·버튼을 가리지 않는다.
- 투명 PNG(긴 변 600px). 반전·재채색·잘라내기 금지. 숫자 팻말(1~5)·칠판 그림은 안내 화면 전용.
- 파일: `assets/Healthy/healthy-001.png` ~ `117`, 순서는 피그마 배치(줄 → 왼쪽부터).

## Mallangi

맬리의 초록 원형 캐릭터. 한 화면에 하나, 메시지에 맞는 포즈로 넣는다.

| 크기 | 쓰는 곳 |
|---|---|
| 64px | 카드 썸네일 |
| 120px | 빈 화면, 권한 화면 |
| 190px | 웰컴·완료 화면 |

- 투명 PNG 그대로: 반전·재채색·잘라내기·테두리 금지. 글자·버튼을 가리지 않는다.
- 의료 상황 포즈(열, 약, 수면, 의사)는 맥락이 맞을 때만.

## MissionCard

오늘의 훈련 한 개. 누르면 바텀시트로 상세가 열린다.

- 구성: 맬랑이 썸네일(64px, `surface-mint`) + 칩 + 이름(`fs-body-lg` 굵게) + 예상 시간(`fs-caption`) + 상태 원. 안쪽 `space-4`, 사이 `space-3`.
- 완료(`is-done`): 면 `surface-mint`, 상태 원에 체크. 작은 일은 작게 축하.
- 하루 미션은 끝이 있는 목록. 다 하면 EmptyState("모두 완료")로 멈출 곳을 만든다.

## ProgressRing

하루 진행률 원. 요약 카드 왼쪽에 둔다.

- 84px, 선 9px, 트랙 `surface-mint`, 막대 `primary`, 가운데 숫자 `fs-title` 카운트 업.
- 다시 그릴 때 이전 값에서 이어서 채운다. 옆에 문장으로도 말한다("3개 중 1개 했어요").

## Skeleton

처음 불러오는 동안 화면 구조를 미리 보여주는 회색 뼈대.

- 실제 레이아웃과 같은 크기·모서리(카드 `radius-lg`). 0.9초 넘게 걸릴 때만. 동작 줄이기면 반짝임을 끈다.

## SocialLoginButton

간편 로그인 버튼. 가입 시작 화면 위쪽에 두고, 이메일 가입은 아래 텍스트 버튼으로 둔다.

- 각 서비스의 공식 색과 로고를 바꾸지 않는다(이 컴포넌트만 토큰 색 예외).
- 높이 `input-height`, 모서리 `radius-md`, 사이 `space-3`.
- iOS 앱에 다른 간편 로그인이 있으면 Apple 로그인도 넣는다.
- 문구는 "○○로 시작하기"로 통일한다.

## StepIndicator

단계가 정해진 흐름(가입 등)의 현재 위치. 4단계 이하에서만 쓴다.

- 막대 `space-6` 폭, 현재까지 `primary`로 채우고 `space-8`로 늘린다. 시작·완료 화면에서는 숨긴다.

## Switch

누르자마자 반영되는 켜고 끄기(알림, 위치). 저장 버튼이 필요한 선택은 Checkbox.

- 꺼짐: `surface-sub` 트랙 + `border-control` 테두리·썸. 켜짐: `primary` 트랙 + `on-primary` 썸. 색과 썸 위치 둘 다로 상태를 보여준다.
- 썸 움직임만 `ease-spring-soft`.
- 설명까지 한 줄 전체(`m-setting`)를 label로 감싼다.

## TabBar

화면 아래에 떠 있는 캡슐 탭바(플로팅 탭바). 앱의 주요 메뉴 4개를 둔다.

- 메뉴: 오늘 · 기록 · 두뇌활동 · 내정보. 아이콘(`icon`) + 라벨(`fs-label-sm`)을 항상 함께. 글자만 있는 탭 금지.
- 모양: 좌우·아래 `space-4`, 높이 `tabbar-height`, `radius-pill`, 유리 면 `glass-strong` + blur 20px, `shadow-card`.
- **선택 알약은 미끄러져 이동한다**(슬라이딩 인디케이터): 누르면 이전 탭과 새 탭에 걸쳐 늘어났다가 `duration-enter`·`ease-enter`로 새 탭 크기로 줄며 자리 잡는다. 선택 탭만 채운 아이콘(`primary`) + 진한 라벨.
- **새 소식 점**: 아이콘 오른쪽 위 `m-dot`. 숫자는 쓰지 않는다.
- **말풍선**(`m-tip`): 특정 탭을 꼬리로 가리키는 안내. 사실만 쓴다("오늘 활동 1개 남았어요"). "곧 사라져요" 같은 가짜 마감 금지. X로 닫으면 다시 띄우지 않는다.
- **컨텍스트 탭바**: 깊은 영역(예: 두뇌활동 › 게임 모음)에서는 왼쪽에 떠 있는 둥근 뒤로 가기 버튼(`m-tabbar-back`) + 그 영역의 하위 탭(`m-tabbar--context`)으로 바뀐다. 돌아가면 하위 탭이 모였다가 주요 탭으로 다시 펼쳐진다.
- 같은 탭을 다시 누르면 맨 위로 스크롤. 몰입 플로우에서는 숨긴다. 시트·다이얼로그는 탭바보다 위 층.
- 두 OS 같은 모양. 안드로이드는 유리 흐림만 8px로.

## TextField

글자를 입력받는 칸. 라벨은 칸 위에 계속 보이게 두고, 플레이스홀더는 예시로만 쓴다.

- 구조: `m-field` › 라벨(`fs-label`) + `m-input`(높이 `input-height`, 값 `fs-body-lg`) + 메시지(`fs-caption`). 사이 `space-2`.
- 상태: 기본 · 포커스(`is-focus`) · 오류(`is-error`) · 완료(`is-ok`).
- 오류는 칸을 벗어날 때 검사해 칸 바로 아래 인라인 에러로. 무엇을 고치면 되는지 말한다.
- 비밀번호: 강도 표시기 `m-meter`(data-level 1~4) + "보기" 버튼.
- 안드로이드 15 이상에서 키보드가 저장 버튼을 가리지 않는지 확인한다.

## Toast

잠깐 떴다 사라지는 결과 알림. 되돌리기 버튼이 있으면 스낵바.

- 2초(스낵바 4초). 탭바 위 `space-4`. 문구는 끝난 일을 말한다("운동 훈련을 마쳤어요").
- iOS에는 시스템 토스트가 없으므로 두 OS 모두 이 앱 안 토스트를 쓴다.
