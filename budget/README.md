# 지쏘 가계부

폰과 PC에서 같이 쓰는 가계부 웹페이지예요. 데이터는 내 구글 시트에 저장돼요.

- 화면: `index.html` (이 폴더)
- 저장소 역할: `apps-script.gs` (구글 시트에 붙여넣는 코드)

## 1. 페이지 열기 (깃허브 Pages)

1. 저장소 설정 → Pages 로 이동: https://github.com/butblank-oss/g-sso/settings/pages
2. Source: **Deploy from a branch**, Branch: **claude/nice-heisenberg-dzym9d** / **(root)** → Save
3. 1~2분 뒤 이 주소로 열려요: https://butblank-oss.github.io/g-sso/budget/
4. 폰에서는 열고 나서 **홈 화면에 추가** 해두면 앱처럼 써요
   - 아이폰: 사파리 공유 버튼 → 홈 화면에 추가
   - 안드로이드: 크롬 메뉴(⋮) → 홈 화면에 추가

## 2. 폰·PC 동기화 연결 (처음 한 번, 5분)

1. 새 구글 시트 만들기: https://sheets.new (이름 예: 지쏘 가계부 데이터)
2. 메뉴 **확장 프로그램 → Apps Script** 열기
3. 원래 있던 코드를 지우고 `apps-script.gs` 내용을 전부 붙여넣기
   - 파일 보기: https://github.com/butblank-oss/g-sso/blob/claude/nice-heisenberg-dzym9d/budget/apps-script.gs
4. 맨 위 `SECRET` 값을 나만 아는 비밀번호로 바꾸고 저장 (Ctrl+S)
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 권한 허용 (구글 계정 선택 → 고급 → 이동 → 허용)
6. 나온 **웹 앱 URL** 복사
7. 가계부 페이지 **설정 → 폰·PC 동기화** 에 URL 과 비밀번호 넣고 **연결하고 불러오기**
8. 다른 기기에서도 7번만 똑같이 하면 같은 내역이 보여요

> 주소와 비밀번호는 각 기기 브라우저에만 저장되고, 깃허브(공개 저장소)에는 올라가지 않아요.
> 비밀번호를 아는 사람만 내 시트를 읽고 쓸 수 있으니 남에게 알려주지 마세요.

## 3. 쓰는 법

| 하고 싶은 것 | 어디서 |
|---|---|
| 현금·이체 기록 | 오른쪽 아래 **+** 버튼 (PC는 왼쪽 아래 **기록하기**) |
| 카드 내역 한꺼번에 넣기 | **카드내역** 탭 → 카드 고르기 → 카드사 엑셀 파일 올리기 → 날짜·가맹점·금액 칸 확인 → 미리보기에서 분류 확인 → 저장 |
| 분류 안 된 내역 정리 | 홈의 노란 알림 → **분류하기** |
| 예산 바꾸기 | **설정 → 한 달 예산** |
| 카드 추가·삭제 | **설정 → 결제수단** |
| 자동 분류 단어 추가 | **설정 → 자동 분류 규칙** (예: 올리브영 → 쇼핑/미용) |
| 백업 | **설정 → 백업 파일 받기 / CSV(엑셀용)** |

## 알아둘 점
- 카드사 엑셀(xlsx·xls·csv)을 그대로 올리면 날짜·가맹점·금액 칸을 제목 줄을 보고 자동으로 찾아요. 틀리면 3번 칸 고르기에서 바꾸면 돼요.
- 암호가 걸린 엑셀은 못 읽어요. 엑셀에서 연 뒤 암호 없이 다시 저장해서 올려주세요.
- 합계·소계 줄은 자동으로 빠져요.
- 같은 날짜·금액·가맹점 내역은 **이미 있는 내역**으로 표시되고 기본으로 빠져요 (중복 방지).
- 인터넷이 끊겨도 기기에 먼저 저장되고, 다시 연결되면 시트로 보내요.
- 두 기기에서 같은 내역을 동시에 고치면 나중에 고친 쪽이 남아요.
