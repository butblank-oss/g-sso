맬리 앱(어르신 두뇌 건강 훈련)과 치매안심센터 관리자 웹의 규칙. 값은 모두 토큰 이름으로 쓰고, 표에 없는 값은 만들지 않는다.

## 원칙

| | 원칙 | 이렇게 |
|---|---|---|
| 1 | 크게, 또렷하게 | 앱 본문 `fs-body-lg`(17), 최소 `fs-caption`(14). 누르는 곳 `touch-min`(48) 이상 |
| 2 | 한 화면에 한 가지 | 큰 제목 하나, 주요 버튼 하나, 맬랑이 하나 |
| 3 | 끝이 있는 하루 | 무한 피드 금지. 미션은 정해진 개수, 다 하면 "모두 완료" |
| 4 | 정직하게 | 다크패턴 9종 금지(숨은 해지, 미리 체크된 동의, 가짜 마감, 죄책감 버튼, 끼워 팔기, 가짜 희소성, 숨은 비용, 몰래 자동 결제, 끝없는 권유) |
| 5 | 또렷한 면 | 회색 바탕 `bg` + 흰 카드 `surface`. 반투명 유리는 탭바에만 |
| 6 | 색은 적게, 뜻은 하나 | 한 화면에 무채색 + 브랜드 초록 1개(+ 꼭 필요할 때 경고색 1개). 색만으로 뜻을 말하지 않는다 |

## 색

| 역할 | 토큰 | 라이트 | 다크 |
|---|---|---|---|
| 바탕 | `bg` | #E7ECE9 | #0F1714 |
| 카드 | `surface` | #FFFFFF | #17221E |
| 강조 면 | `surface-mint` | #E8F5EE | #18342A |
| 본문 | `text` | #1E2B26 | #E8F0EC |
| 작은 초록 글자 | `text-accent` | #257552 | #7FD0AE |
| 주요 버튼 | `primary` / `on-primary` | #265F4D / 흰색 | #5BBE97 / #0F2A20 |
| 오류 · 주의 | `error` · `warning` | #B8483E · #8A6400 | #F08A80 · #E8C15A |

### 시니어 색 규칙

- **초록은 세 가지 역할만**: `primary` = 누르는 버튼, `text-accent` = 초록 글자(링크·라벨·칩), `surface-mint` = 선택 표시. 다른 초록은 화면 UI에 쓰지 않는다.
- **성공은 색이 아니라 모양으로**: 체크 아이콘 + "완료" 글자. 별도 성공 초록을 두지 않는다(`success`는 `text-accent`와 같다).
- **오류·주의도 색만으로 말하지 않는다**: 아이콘과 문구를 함께.
- **면은 또렷하게**: 회색 바탕 + 흰 카드. 카드 테두리 대신 바탕과의 명도 차이로 구분하고, 입력 칸만 테두리를 둔다.
- **유리 효과는 탭바만**(불투명도 94%). 앱 바·말풍선·알림창은 불투명 면.
- **캐릭터 색은 그림 안에서만**: 헬씨들의 노랑·파랑·분홍 등을 버튼·칩·배경 같은 UI 색으로 가져오지 않는다.
- 나이가 들면 청록·파랑 계열 구분과 대비 감도가 떨어진다. 비슷한 초록 두 개를 나란히 두지 않는다.

- 글자는 `text` → `text-2` → `text-3` → `text-4` 순으로 약해진다. `text-4`는 `surface` 위에서만.
- 원본 브랜드 색 `green-700`은 포커스 링 전용, `green-600`은 쓰지 않음, `mint-500`은 다크 테마 버튼과 그래프 보조색만.
- 상태는 색만으로 말하지 않는다(글자·아이콘 함께). 그래프는 `primary` + `mint-500` 두 색만.
- 모든 글자 토큰은 사용 메모에 적힌 면 위에서 라이트·다크 모두 4.5:1 이상.

## 글자

글꼴은 **Pretendard 하나**. 크기·줄간격·굵기는 `fs-*` · `lh-*` · `fw-*` 변수로만 쓴다.

| 스타일 | 크기 / 줄간격 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| `display` | 32 / 42 | 800 | 웰컴·완료 화면 |
| `title-lg` | 24 / 32 | 800 | 화면 큰 제목 |
| `title` | 20 / 28 | 700 | 시트·다이얼로그 제목 |
| `headline` | 18 / 26 | 700 | 섹션·카드 제목, 접힌 앱 바, 주요 버튼 |
| `body-lg` | 17 / 26 | 400 | 앱 본문 기본, 입력 값 |
| `body` | 16 / 24 | 400 | 설명 |
| `label` | 15 / 22 | 600 | 입력 라벨, 보조 버튼 |
| `caption` | 14 / 20 | 500 | 메타 정보 (앱 최소) |
| `label-sm` | 13 / 18 | 700 | 칩·태그·탭 라벨 (짧은 낱말만) |

관리자 웹: `admin-title` 24/32 · `admin-headline` 17/24 · `admin-body` 15/22 · `admin-caption` 13/18.

- 제목 `text-wrap: balance`, 한국어 `word-break: keep-all`, 줄 맞춤 숫자는 `tabular-nums`.

## 간격 · 모서리 · 그림자

간격은 **4px 단위**: `space-1` 4 · `space-2` 8 · `space-3` 12 · `space-4` 16 · `space-5` 20 · `space-6` 24 · `space-8` 32 · `space-10` 40 (`space-hair` 2는 태그 안쪽만).

| 자리 | 토큰 |
|---|---|
| 앱 화면 좌우 여백 | `space-5` |
| 카드 안쪽 | `space-5` (작은 카드 `space-4`) |
| 목록 카드 사이 | `space-3` |
| 섹션 사이 | `space-6` |
| 라벨과 입력 칸 사이 | `space-2` |

모서리: `radius-xs` 8 태그 · `radius-sm` 12 아이콘 버튼·토스트 · `radius-md` 16 입력·버튼 · `radius-lg` 20 카드 · `radius-xl` 24 패널·다이얼로그 · `radius-sheet` 28 · `radius-pill`.

그림자는 셋뿐: `shadow-card`(호버·탭바), `shadow-float`(다이얼로그·말풍선), `shadow-sheet`. 평소 카드는 `border` 1px.

숫자를 직접 쓰는 예외: 선 두께(1·1.5·2px), 컴포넌트 고유 치수(스위치 52×32, 진행률 원 84, 썸네일 64, 칩 높이 28).

## 모션

| 움직임 | 시간 | 곡선 |
|---|---|---|
| 들어옴(푸시, 시트 열림, 탭 알약 이동) | `duration-enter` 380ms | `ease-enter` |
| 나감(닫힘, 사라짐) | `duration-exit` 240ms | `ease-exit` |
| 호버·눌림 | `duration-fast` 150ms | |
| 스위치 썸·배지 | 280~500ms | `ease-spring-soft` (작은 튕김은 여기만) |

- `transform`·`opacity`만 움직인다. 화면 밖 요소에 포커스 금지. 다시 그릴 때 이전 값에서 이어간다. `prefers-reduced-motion`이면 끈다.
- 축하는 일의 크기에 맞춘다: 미션 1개 = 체크, 하루 완료 = 배지 + 컨페티.

## 내비게이션

- 하단: **떠 있는 캡슐 탭바**(오늘 · 기록 · 두뇌활동 · 내정보). 아이콘 + 라벨, 선택 알약이 미끄러져 이동, 새 소식 점, 사실만 담은 말풍선. 깊은 영역은 컨텍스트 탭바 + 떠 있는 뒤로 가기.
- 상단: 화면 종류별 앱 바 3종(큰 제목형 · 뒤로 가기형 · 닫기형). 자세한 규칙은 AppBar · TabBar.
- 시트·다이얼로그는 탭바보다 위 층.

## 접근성 (어르신 기준)

- 글자 4.5:1 이상(24px 이상·굵은 19px 이상 3:1). 포커스 링 3px `focus-ring`.
- 시스템 글자 크기를 키워도 잘리지 않게 고정 높이 대신 최소 높이.
- 제스처에는 버튼 대체 수단. 아이콘 버튼에는 `aria-label`.
