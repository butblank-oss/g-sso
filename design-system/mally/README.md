맬리 앱(어르신용 두뇌 건강 훈련)과 치매안심센터 관리자 웹을 같은 손길로 만들기 위한 규칙이다. 색과 캐릭터는 맬리 사업소개 덱에서, 화면 규칙은 지쏘 UI/UX 스킬로 만든 프로토타입에서 왔다. 대상: iOS · 안드로이드 · 모바일 웹 · 관리자 웹(PC). 라이트와 다크 두 테마.

## 원칙

1. **크게, 또렷하게.** 앱 본문은 `body-lg`(17px), 최소 `caption`(14px). 누르는 요소는 `touch-min`(48px) 이상, 주요 버튼은 `button-height`(58px).
2. **한 화면에 한 가지 일.** 화면 제목 하나, 주요 버튼 하나, 맬랑이 하나.
3. **끝이 있는 하루.** 무한 피드를 만들지 않는다. 하루 미션은 정해진 개수, 다 하면 "모두 완료"로 멈춘다.
4. **정직하게.** 다크패턴 9종(숨은 해지, 미리 체크된 동의, 가짜 마감, 죄책감 버튼, 끼워 팔기, 가짜 희소성, 숨은 비용, 몰래 자동 결제, 끝없는 권유)을 쓰지 않는다.
5. **은은한 유리.** 바탕은 거의 흰색 `bg`, 연한 민트 빛 한두 겹, 면은 `glass`/`glass-strong` + blur. 화려한 그라데이션 금지.

## 말투 (콘텐츠 기본)

- "~해요"체로 짧게. 한 문장 한 가지. 어려운 한자어·영어 대신 쉬운 말: "인증하기" → "확인하기", "알림 수신 동의" → "알림 받기", "프로필 편집" → "내 정보 바꾸기".
- 사용자를 "○○님"으로 부른다. "고객님", "회원님" 금지.
- 버튼은 결과를 말하는 동사: "가입 완료하기", "오늘의 훈련 시작하기", "나중에 할게요". "확인", "예/아니요"만 쓰지 않는다.
- 오류는 무엇을 고치면 되는지: "8자 이상, 영문과 숫자를 모두 넣어 주세요". 사과·탓하는 말 금지.
- 숫자는 천 단위 콤마, 단위 붙여 쓰기(891명, 68.5%). 시간은 "약 5분".
- 이모지를 장식으로 쓰지 않는다. em 대시(—) 대신 가운뎃점(·)이나 콜론.
- 실제 문구 예: "매일 조금씩, 두뇌 건강을 챙겨요" / "필수 항목만 동의해도 가입할 수 있어요." / "오늘 할 일 끝! 잘하셨어요."

## 색

- 라이트: 바탕 `bg`, 면 `surface`, 보조 면 `surface-sub`, 강조 면 `surface-mint`. 주요 버튼 `primary`(= `green-900`) 위 `on-primary`.
- 다크: `primary`가 `mint-500`으로 바뀌고 그 위 글자는 진한 `on-primary`(#0F2A20). 흰 글자를 민트 위에 올리지 않는다.
- 글자: `text` → `text-2` → `text-3` → `text-4` 순으로 약해진다. `text-4`는 `bg`·`surface` 위에서만.
- 작은 초록 글자(칩, 라벨, 링크)는 `text-accent`. 원본 브랜드 색 `green-700`은 흰 바탕 4.3:1이라 19px 굵게 이상·아이콘·포커스 링에만.
- `mint-500`은 장식·면·막대·켜진 스위치용. 흰 바탕 위 글자나 테두리로 쓰지 않는다(2.3:1).
- 상태: 오류 `error`/`error-bg`, 주의·예정 `warning`/`warning-bg`, 성공 `success`. 상태는 색만으로 말하지 않고 글자·아이콘을 함께.
- 그래프·진행률은 `primary` + `mint-500` 두 색만. `yellow-highlight`는 진한 면 위 핵심 숫자 하나에만.
- 포커스 링: `focus-ring` 3px 실선, 오프셋 2~3px. 모든 면에서 3:1 이상.

## 글자

- 글꼴은 Pretendard(가변, `fonts/PretendardVariable.woff2`) 하나로 모든 글자를 통일한다. 굵기는 가변 축(400·500·600·700·800)으로 조절. 대체: -apple-system, Apple SD Gothic Neo, Noto Sans KR.
- 앱 스타일: `display` 32 · `title-lg` 25 · `title` 21 · `headline` 18 · `body-lg` 17 · `body` 16 · `label` 15 · `caption` 14 · `button` 18.
- 관리자 웹 스타일: `admin-title` 24 · `admin-headline` 17 · `admin-body` 15 · `admin-caption` 13.
- 제목에 `text-wrap: balance`, 한국어는 `word-break: keep-all`. 숫자가 줄을 맞추는 곳은 `tabular-nums`.
- 플랫폼 기본 글꼴(SF, Roboto, 삼성 One UI)로 바뀌어도 줄바꿈이 깨지지 않게 긴 문구는 두 OS에서 따로 확인한다.

## 간격 · 모서리 · 그림자

- 앱 화면 좌우 여백 `space-screen`(22px), 위 `space-5`, 아래 `space-6`. 카드 안쪽 `space-4`, 카드 사이 `space-3`(목록은 10px), 섹션 사이 `space-6`.
- 모서리: 입력·간편 로그인 `radius-md`, 주요 버튼 `radius-lg`, 카드 `radius-xl`, 요약 패널·다이얼로그 `radius-2xl`, 바텀시트 `radius-sheet`, 칩 `radius-pill`.
- 그림자는 세 개뿐: 카드 호버 `shadow-card`, 떠 있는 면 `shadow-float`, 바텀시트 `shadow-sheet`. 평소 카드는 그림자 없이 `border` 1px.
- 강조 카드에 왼쪽 컬러 띠를 붙이지 않는다. 강조는 `surface-mint` 면으로.

## 모션

- 들어올 때 `ease-enter`(감속) `duration-enter`(380ms), 나갈 때 `ease-exit`(가속) `duration-exit`(240ms). 호버·눌림 `duration-fast`.
- **오버슈트(튕김) 금지.** 예외: 스위치 썸, 배지 등장만 `ease-spring-soft`.
- 움직이는 속성은 `transform`과 `opacity`만. `top`·`height`·`margin` 애니메이션 금지.
- 화면 밖 요소에 포커스를 주지 않는다. 시트·다이얼로그는 다 열린 뒤 `focus({preventScroll:true})`.
- 값이 바뀌어 다시 그릴 때 0부터 다시 차오르지 않고 이전 값에서 이어간다.
- 축하는 일의 크기에 맞춘다: 미션 1개 = 체크 그리기, 하루 완료 = 배지 + 컨페티, 가입 완료 = 축하 맬랑이 + 컨페티.
- `prefers-reduced-motion`이면 애니메이션을 끈다(컨페티 포함).

## 접근성 (어르신 기준)

- 글자 대비 4.5:1 이상(24px 이상·굵은 19px 이상은 3:1). 이 시스템의 글자 토큰은 사용 메모에 적힌 면 위에서 라이트·다크 모두 기준을 넘는다.
- 시스템 글자 크기 설정(iOS Dynamic Type, 안드로이드 글꼴 크기)을 따라 커져도 잘리지 않게 고정 높이 대신 최소 높이를 쓴다.
- 제스처에는 버튼 대체 수단을 둔다(밀어서 삭제 → 편집 버튼, 시트 끌어 닫기 → 딤 누르기).
- 아이콘만 있는 버튼에는 `aria-label`. 맬랑이 장식 이미지는 `alt=""`, 의미가 있으면 포즈를 설명한다.

## 플랫폼 (iOS · 안드로이드 · 웹 · 관리자 웹)

공통: 브랜드 색, 글자 체계, 문구, 아이콘, 맬랑이. 다르게: OS와 만나는 부분.

| 항목 | iOS | 안드로이드 |
|---|---|---|
| 앱 바 제목 | 가운데 | 왼쪽 |
| 뒤로 가기 | ‹ + 이전 화면 이름, 가장자리 밀기 | ← 아이콘, 시스템 제스처·버튼 |
| 확인 창 | Dialog의 iOS 알림창 | Dialog의 안드로이드 다이얼로그 |
| 하단 탭바 | 떠 있는 캡슐, 선택 탭 알약 배경 | 같은 캡슐(유리 흐림만 약하게) |
| 짧은 알림 | 앱 안 Toast | 앱 안 Toast (시스템 토스트와 모양 맞춤) |
| 아래 여백 | 홈 인디케이터 안전 영역 | 제스처 바·3버튼, 안드로이드 15부터 직접 여백 |
| 권한 팝업 | OS 기본, 앞에 설명 화면 | OS 기본(13 이상 알림 권한), 앞에 설명 화면 |

- 모바일 웹: iOS 규칙을 기본으로 하되 뒤로 가기는 브라우저에 맡긴다.
- 관리자 웹(PC): AdminShell + DataTable. 최소 폭 1280px, 본문 15px, 최소 13px. 마우스 호버 상태를 반드시 만든다.

## 맬랑이와 로고

- 로고: 밝은 면에는 `Logos/mally-logo.png`(컬러), 진한 면(`green-950`, `green-900`)에는 `Logos/mally-logo-white.png`. 앱 바에서 높이 24px, 시작 화면 30px. 늘이거나 색을 바꾸지 않는다.
- 맬랑이: 한 화면에 하나, 메시지에 맞는 포즈(Mallangi 컴포넌트의 표). 크기 62~190px. 투명 PNG 그대로, 반전·재채색·잘라내기 금지.
- 모든 글자는 Pretendard 하나로 통일한다: 앱, 관리자 웹, 소개서·발표 자료 모두. 다른 글꼴(Paperlogy 등)을 섞지 않는다.

## 아이콘

- 선 아이콘, 24px 격자, 선 두께 2px, 둥근 끝(round cap/join). 색은 글자 색을 따른다.
- 지금은 SVG를 화면마다 직접 그려 쓴다(전용 아이콘 세트 없음). 세트를 정하면 이 절을 바꾼다.
- 이모지를 아이콘 대신 쓰지 않는다.
