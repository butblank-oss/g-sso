화면 맨 위 제목 줄로, **iOS와 안드로이드를 다르게 만든다.**

| | iOS (`m-appbar--ios`) | 안드로이드 |
|---|---|---|
| 제목 | 가운데 정렬 | 왼쪽 정렬 |
| 뒤로 가기 | ‹ + 이전 화면 이름(`m-back-ios`), 왼쪽 가장자리 밀기도 지원 | ← 아이콘만(`m-iconbtn`), 시스템 뒤로 가기 제스처·버튼도 같은 화면으로 |
| 오른쪽 행동 | 텍스트 버튼 | 아이콘 버튼 |

- 높이 `appbar-height`, 누르는 요소는 `touch-min` 이상.
- 홈 화면은 제목 대신 맬리 로고(높이 24px)와 오른쪽 연속 기록 칩.

## 앱 바 3종 (화면 종류별로 하나만)

| 종류 | 언제 | 모양 |
|---|---|---|
| 큰 제목형 | 탭 첫 화면(오늘·기록·두뇌활동·내정보) | 맨 위 24px 큰 제목 + 오른쪽 아이콘(알림 등). 스크롤 36px 넘으면 유리 면 작은 제목 바(17px)가 나타남(접히는 큰 제목) |
| 뒤로 가기형 | 탭 안에서 더 들어간 화면 | 처음부터 작은 제목 바 고정. iOS ‹ + 이전 화면 이름·제목 가운데, 안드로이드 ← ·제목 왼쪽. 탭바는 보임 |
| 닫기형 | 몰입 플로우(운동·게임·마음다루기) | 진행 막대 + "1 / 5" 왼쪽, 닫기(X) 오른쪽 위로 통일. 누르면 "그만할까요?" 확인 창. 탭바는 숨김 |

- 접힘은 `opacity`·`transform`만 쓴다. 상태 표시줄 영역은 항상 바탕색으로 칠해 글자가 겹치지 않게 한다.
- 제목이 월 선택처럼 눌리는 경우 화살표(⌄)를 붙이고, 접힌 바에는 짧은 이름("9월 성과")을 쓴다.
