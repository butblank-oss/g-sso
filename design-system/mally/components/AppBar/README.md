화면 맨 위 제목 줄로, **iOS와 안드로이드를 다르게 만든다.**

| | iOS (`m-appbar--ios`) | 안드로이드 |
|---|---|---|
| 제목 | 가운데 정렬 | 왼쪽 정렬 |
| 뒤로 가기 | ‹ + 이전 화면 이름(`m-back-ios`), 왼쪽 가장자리 밀기도 지원 | ← 아이콘만(`m-iconbtn`), 시스템 뒤로 가기 제스처·버튼도 같은 화면으로 |
| 오른쪽 행동 | 텍스트 버튼 | 아이콘 버튼 |

- 높이 `appbar-height`, 누르는 요소는 `touch-min` 이상.
- 홈 화면은 제목 대신 맬리 로고(높이 24px)와 오른쪽 연속 기록 칩.
