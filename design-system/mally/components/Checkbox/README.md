여러 개를 고르고 저장해야 반영되는 선택에 쓴다. 바로 반영되는 켜고 끄기는 Switch를 쓴다.

- 한 줄 전체가 눌리는 영역(`m-check`, 높이 `touch-min` 이상).
- 약관 동의: 전체 동의와 개별 동의를 연동한다. 하나라도 풀면 전체 동의도 풀린다.
- 필수/선택은 태그(`m-tag--req`, `m-tag--opt`)로 표시한다. **선택 항목을 미리 체크하지 않는다**(다크패턴: 미리 체크된 동의).
- 꺼진 테두리는 `border-control`(3:1 이상), 켜지면 `primary` 채움 + `on-primary` 체크.
