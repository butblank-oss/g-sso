| | iOS 알림창(`m-alert`) | 안드로이드 다이얼로그(`m-dialog`) |
|---|---|---|
| 정렬 | 가운데 | 왼쪽 |
| 버튼 | 아래 가로로 나눔: 취소 왼쪽, 확인 오른쪽(굵게) | 오른쪽 아래 텍스트 버튼: 취소 → 확인 |
| 위험한 행동 | 빨간 글자(`error`) | 빨간 글자(`error`) |

- 제목은 질문으로, 버튼은 동사로: "훈련을 그만할까요?" / "계속하기", "그만하기". "예/아니요"는 쓰지 않는다.
- 거절 버튼에 죄책감 주는 문구를 쓰지 않는다(다크패턴).
- 저장 알림 같은 가벼운 알림에는 쓰지 않는다 → Toast.
