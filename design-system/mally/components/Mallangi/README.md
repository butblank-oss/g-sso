맬리의 초록 원형 캐릭터로, 한 화면에 하나만 메시지에 맞는 포즈로 넣는다.

- 크기: 카드 썸네일 62~72px, 빈 화면 120px, 시작·권한 화면 120~150px, 웰컴·완료 화면 190px.
- 메시지별 포즈: 인사(손 흔들기·공손한 인사), 고민·검색 없음(생각 중), 일정·알림(일정 확인), 두뇌 게임(책 읽기), 운동(아령), 마음(손 모은 평온), 응원(손 들고 응원), 축하(고깔), 마무리(활짝 웃기), 성장(새싹 물주기), 금지·주의(X 표시).
- 투명 PNG를 그대로 쓴다: 좌우 반전, 색 변경, 잘라내기, 테두리 금지. 글자·버튼을 가리지 않는다.
- 의료 상황 포즈(열, 약, 수면, 의사)는 맥락이 맞을 때만.
