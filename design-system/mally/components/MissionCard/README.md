오늘의 훈련 한 개를 보여주는 카드로, 누르면 바텀시트로 상세가 열린다.

- 구성: 맬랑이 썸네일(62px, `surface-mint` 받침) + 카테고리 칩 + 이름(17px 굵게) + 예상 시간 + 상태 원.
- 완료(`is-done`): 면이 `surface-mint`로 바뀌고 상태 원에 체크가 그려진다(체크 그리기, `duration-celebrate`). 작은 일은 작게 축하한다.
- 하루 미션은 3개처럼 끝이 있는 목록으로 둔다. 다 하면 EmptyState("모두 완료")로 바꿔 멈출 곳을 만든다.
- 썸네일 맬랑이는 미션 종류와 맞춘다: 두뇌 게임=책 읽기, 운동=아령, 마음=손 모은 평온.
