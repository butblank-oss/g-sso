- 각 서비스의 공식 색과 로고를 바꾸지 않는다: 카카오 `#FEE500` 위 85% 검정 글자, 네이버 `#03C75A`, Google 흰 바탕 + 회색 테두리, Apple 검정(다크 테마에서는 흰색).
