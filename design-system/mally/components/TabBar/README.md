화면 아래에 떠 있는 캡슐 모양 탭바(플로팅 탭바)로, 앱의 주요 메뉴 4개를 둔다.

- 메뉴: 오늘 · 기록(성과) · 두뇌활동(더 해보기) · 내정보. 아이콘(25px) + 라벨(12.5px)을 항상 함께 둔다. 글자만 있는 탭은 쓰지 않는다.
- 모양: 좌우 14px, 아래 안전 영역 위에 떠 있는 캡슐(`radius-pill`), 높이 64px, 유리 면 `glass-strong` + blur 20px, 얇은 테두리와 `shadow-card`.
- 선택: 선택한 탭만 알약 배경(`surface-mint` 계열 8%), 채운 아이콘(`primary`), 진한 라벨. 나머지는 선 아이콘 + `text-3`.
- 내용이 탭바 뒤로 비쳐 지나가므로 스크롤 영역 아래 여백을 탭바 높이 + 40px 이상 둔다.
- 같은 탭을 다시 누르면 맨 위로 스크롤한다.
- 몰입 화면(운동·게임·마음다루기 플로우)에서는 숨긴다. 하위 화면(뒤로 가기형)에서는 보인다.
- 바텀시트·다이얼로그는 탭바보다 위 층에 둔다(딤이 탭바까지 덮어야 한다).
- 플랫폼: iOS와 안드로이드 모두 같은 캡슐. 안드로이드는 유리 흐림을 8px로 줄인다(성능).
