화면 아래에 떠 있는 캡슐 탭바(플로팅 탭바). 앱의 주요 메뉴 4개를 둔다.

- 메뉴: 오늘 · 기록 · 두뇌활동 · 내정보. 아이콘(`icon`) + 라벨(`fs-label-sm`)을 항상 함께. 글자만 있는 탭 금지.
- 모양: 좌우·아래 `space-4`, 높이 `tabbar-height`, `radius-pill`, 유리 면 `glass-strong` + blur 20px, `shadow-card`.
- **선택 알약은 미끄러져 이동한다**(슬라이딩 인디케이터): 누르면 이전 탭과 새 탭에 걸쳐 늘어났다가 `duration-enter`·`ease-enter`로 새 탭 크기로 줄며 자리 잡는다. 선택 탭만 채운 아이콘(`primary`) + 진한 라벨.
- **새 소식 점**: 아이콘 오른쪽 위 `m-dot`. 숫자는 쓰지 않는다.
- **말풍선**(`m-tip`): 특정 탭을 꼬리로 가리키는 안내. 사실만 쓴다("오늘 활동 1개 남았어요"). "곧 사라져요" 같은 가짜 마감 금지. X로 닫으면 다시 띄우지 않는다.
- **컨텍스트 탭바**: 깊은 영역(예: 두뇌활동 › 게임 모음)에서는 왼쪽에 떠 있는 둥근 뒤로 가기 버튼(`m-tabbar-back`) + 그 영역의 하위 탭(`m-tabbar--context`)으로 바뀐다. 돌아가면 하위 탭이 모였다가 주요 탭으로 다시 펼쳐진다.
- 같은 탭을 다시 누르면 맨 위로 스크롤. 몰입 플로우에서는 숨긴다. 시트·다이얼로그는 탭바보다 위 층.
- 두 OS 같은 모양. 안드로이드는 유리 흐림만 8px로.
