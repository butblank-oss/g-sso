글자를 입력받는 칸으로, 라벨은 칸 위에 계속 보이게 두고 플레이스홀더는 예시로만 쓴다.

- 구조: `m-field` > `m-field__label` + `m-input` + `m-field__msg`. 상태: 기본, 포커스(`is-focus`), 오류(`is-error`), 완료(`is-ok`).
- 오류는 칸을 벗어날 때(blur) 검사해서 칸 바로 아래 인라인 에러로 보여준다. 팝업 경고창은 쓰지 않는다. 문구는 무엇을 고치면 되는지 말한다: "이메일 형식을 확인해 주세요".
- 비밀번호에는 강도 표시기 `m-meter`(data-level 1~4)와 "보기" 버튼을 붙인다.
- 글자 수 제한이 있으면 라벨 오른쪽에 카운터(0/10)를 둔다.
- 플랫폼: 이메일은 `type=email`, 숫자는 `inputmode=numeric`으로 맞는 키보드를 띄운다. 안드로이드 15 이상에서는 키보드가 저장 버튼을 가리지 않는지 확인한다.
